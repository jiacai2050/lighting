# API Reference

The interactive HTML API reference for Lighting is automatically generated from Zig doc comments via `zig build docs`.

- **[👉 Launch Lighting API Documentation](/lighting/apidocs/index.html)**

---

### Local Generation

You can build and preview the API documentation locally:

```bash
# Build the HTML API documentation
zig build docs

# Preview with a local web server
python3 -m http.server -d zig-out/docs 8080
```
